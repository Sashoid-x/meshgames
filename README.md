# MeshGames

[![Kotlin](https://img.shields.io/badge/Kotlin-2.0.21-purple.svg)](https://kotlinlang.org)
[![Platform](https://img.shields.io/badge/Platform-Android%20%7C%20JVM-green.svg)](https://android.com)
[![Protocol](https://img.shields.io/badge/Meshtastic-LoRa%20Mesh-blue.svg)](https://meshtastic.org)

Набор из 6 классических настольных игр для Android и автономный игровой сервер с сильным искусственным интеллектом, работающие поверх беспроводной оффлайн-сети **[Meshtastic](https://meshtastic.org)** (LoRa радиоканал).

Никакого интернета, сотовой связи или централизованных облачных серверов: ход передаётся компактным радиопакетом между нодами.

---

## 🎮 Доступные игры

| Игра | Обозначение | Особенности и правила |
|---|:---:|---|
| **Крестики-нолики** | `✕ ○` | Классическое поле 3×3, минимальный размер пакета (1 байт на ход). |
| **Шашки** | `⬤` | Русские шашки: обязательное взятие, бой цепочкой с выбором маршрута, превращение в дамки. |
| **Шахматы** | `♞` | Полные правила FIDE: рокировки, взятие на проходе, превращение пешек, мат/пат, правило 50 ходов, троекратное повторение. |
| **Морской бой** | `⛴` | Поле 10×10, флот 4/3/2/1 палуб без соприкосновений. Автоматическая и ручная расстановка, честный статус готовности `READY`. |
| **Балда** | `Б` | Поле 5×5, встроенный словарь (66 000+ существительных), детерминированное стартовое слово из `sessionId`. Спорные слова вне словаря решает соперник; взаимозаменяемость пар букв (е/ё, и/й, ь/ъ). |
| **Дурак** | `♦` | 36 карт на двоих, подкидной: стол до 6 атак, подкидывание по номиналу любой карты на столе, взятие/бито. Колода детерминирована от `sessionId` — скрытые карты не передаются по радио. |

## 🏗 Состав проекта

Проект разделён на два основных модуля с общим кодом движков и протокола:

1. **`app` — Android-клиент (Jetpack Compose):**
   - Графический интерфейс для смартфонов и планшетов (портретная и альбомная ориентация).
   - Взаимодействие с локальным «Mesh Bridge» форка Meshtastic-Android по TCP (`127.0.0.1:8090`).
   - Игрок идентифицируется номером и именем своей LoRa-ноды через служебный кадр `HELLO` (`0x49`).
   - Push-уведомления о входящих приглашениях с действиями «Принять»/«Отклонить».
   - Выбор сложности игры при отправке приглашения бот-серверу (Легко / Средне / Сложно).
   - Автоматическое сохранение сессий в JSON и бесшовное восстановление после перезагрузки.

2. **`bot_server` — Автономный игровой сервер и умный ИИ-бот (Kotlin JVM):**
   - Headless демон для Linux/macOS/Windows, Raspberry Pi или домашнего сервера.
   - Подключается напрямую к ноде Meshtastic по PhoneAPI (TCP порт `4403`) через Protobuf Stream Framing.
   - **Многопоточность:** может одновременно вести десятки партий с разными игроками по радиосети.
   - **Умный ИИ (`Smart AI`):**
     - *Крестики-нолики:* полный Minimax (непобедим на высокой сложности).
     - *Шахматы / Шашки:* Minimax с Alpha-Beta отсечением и позиционными таблицами (PST).
     - *Морской бой:* Heatmap-анализ вероятностей + прицельное добивание по линии.
     - *Балда:* DFS-поиск по словарю максимальных и тактических слов.
     - *Дурак:* тактический учёт карт, сохранение козырей на эндшпиль.
   - **Статистика и таблица лидеров:**
     - Автоматический сбор и учет результатов всех завершённых игр (`bot_data/stats.json`).
     - Интерактивная консольная команда `table` (или `t`) для вывода таблицы побед/поражений.
     - Обработка команды `!table` (или `!таблица`) в канале Meshtastic: бот публикует краткий рейтинг игроков прямо в эфир (соблюдая лимит $\le 100$ символов кириллицы).

## 📡 Протокол и оптимизация радиоканала

Подробное описание спецификации см. в [docs/PROTOCOL.md](docs/PROTOCOL.md).

- **Компактный Envelope v2 (12 байт):**
  `[0]=0x47, [1]=2, [2]=type, [3]=0, [4..5]=sessionId, [6..7]=seq, [8..11]=cumAck + bitmap`
- **Никаких standalone ACK и ожидания:**
  Подтверждение доставки осуществляется кумулятивным `cumAck` в заголовке ответного кадра (piggyback). Для экстренного гашения повторов без полезной нагрузки используется легковесный `MsgType.ACK_ONLY = 16`.
- **Эфирная дисциплина «Повторяй и не жди» (`ReliableChannel`):**
  - Обычные кадры: расписание гэпов `[6, 10, 16, 30, 60]` секунд (первый гэп 6 с предотвращает коллизии полудуплекса LoRa при среднем RTT 4–5 с).
  - Критичные кадры (`INVITE`, `READY`, `GAME_OVER`, `SESSION_DELETE`): `[8, 14, 25, 45, 60]` секунд.
  - Вечный режим ожидания: после базового расписания неподтверждённый кадр повторяется 1 раз в 2 минуты, гарантируя доставку при выходе оппонента из тени без лавинной нагрузки на эфир.
- **Минимизация радио-трафика:**
  - *Piggyback silence:* ответный ход или явный ACK мгновенно гасит очередь повторов.
  - *Пакетная агрегация (`BATCH = 17`):* объединение нескольких накопленных кадров в один слот передачи.
  - *Компактная Балда:* дельта-кодирование пути слова 2 битами на шаг вместо передачи полных координат.
  - *Экономная синхронизация:* кадры `SYNC_REQ` / `SYNC_RES` не передают пустые хвосты журнала.
- **Изоляция трафика:**
  Игры используют выделенный `portnum = 69` (`SIMULATOR_APP`), не забивая текстовые каналы пользователей.

## 🛠 Сборка и запуск

### Требования
- JDK 17+ (рекомендуется JDK 21+)
- Android SDK (compileSdk 35+, targetSdk 35)

### Сборка Android APK
```bash
./gradlew :app:assembleDebug
```
Собранный файл: `app/build/outputs/apk/debug/app-debug.apk`

### Сборка и запуск бот-сервера
Сборка единого fatJar:
```bash
./gradlew :bot_server:fatJar
```
Собранный архив: `bot_server/build/libs/meshgames-bot-server-all.jar` (~7.6 МБ)

Быстрый запуск сервера:
```bash
cd bot_server
./run.sh --host 192.168.1.50 --port 4403 --channel 0 --hop-limit 3
```

Флаги запуска `bot_server`:
- `--host`, `-h` — IP-адрес ноды Meshtastic (по умолчанию `127.0.0.1`).
- `--port`, `-p` — TCP PhoneAPI порт ноды (по умолчанию `4403`).
- `--channel`, `-c` — индекс радиоканала (по умолчанию `0`).
- `--hop-limit`, `-hl` — лимит ретрансляций LoRa (по умолчанию `3`).
- `--name`, `-n` — явное имя бота (высший приоритет над именем ноды).
- `--difficulty`, `-d` — сложность ИИ по умолчанию: `easy`, `medium`, `hard` (по умолчанию `hard`).
- `--data-dir` — директория для сохранения логов, статистики и сессий (по умолчанию `bot_data`).

### Запуск тестов
Комплексный прогон всех юнит-тестов (движки, протокол, ИИ, сетевой стек, синхронизация):
```bash
./gradlew :app:testDebugUnitTest :bot_server:test
```

## 📻 Как играть по радиоканалу

1. **На обоих телефонах:**
   - Установить форк **[Meshtastic-Android-ADV](https://github.com/Sashoid-x/Meshtastic-Android/releases)** с поддержкой «Mesh Bridge» и **MeshGames**.
   - В форке Meshtastic: *Settings* → *Radio Config* → *Mesh Bridge* — включить переключатель и настроить portnum (по умолчанию `69`).
2. **В приложении MeshGames:**
   - Открыть приложение → экран «Подключение» → нажать «📱 Радиосеть (мост)».
   - Приложение автоматически подключается к локальному мосту и отправляет Presence-кадр в эфир.
   - В списке сессий нажать «＋ Новая игра» → выбрать соперника (или бот-сервер) → выбрать игру (и сложность) → отправить приглашение.
3. **Игра продолжается оффлайн!** Даже если свернуть приложение или выключить экран, Foreground-сервис продолжает слушать эфир и уведомляет о ходах оппонента.
