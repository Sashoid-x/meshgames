# Словарь для Балды — паспорт источника

Статус: сырой материал для будущего ассета `assets/balda_dict.txt.gz`
(этап 2 — подготовка ассета, см. пайплайн ниже). Проверен 18.10.2026.

## Источник

- Оригинал: http://blog.kislenko.net/show.php?id=1678
  («Все существительные русского языка в простом формате»),
  файл `8381.zip` → `singular.txt`.
- В свою очередь список вырезан из морфологического словаря Хагена
  (http://www.speakrus.ru/dict/#morph-paradigm, hagen-morph.rar):
  отобраны существительные, именительный падеж, единственное число,
  мужской/женский род; без имён собственных, без «ё».
- Классическое правило Балды («существительное, и. п., ед. ч.») —
  попадание прямое.

## Состав (проверено)

- 67,773 строк; кодировка UTF-8, CRLF, по слову на строку, нижний регистр.
- 67,061 чисто кириллических; 713 строк — гидратные фразы
  («а-ля фуршет», «адрес-календарь») — отбрасываются.
- 66 дубликатов — dedup.
- «ё» — 0; латинских протечек — 1 (удалить фильтром).
- Слов ровно из 5 букв — 4,163 (пул стартовых слов, `sid % size`).
- Размер: 1,384,169 байт; gzip -9 ≈ 260 КБ → APK +0.26 МБ.
- Сортировка НЕ по UTF-8 codepoint — при подготовке ассета
  пересортировать (нужна бинарному поиску).

## Пайплайн подготовки ассета

1. дроп строк не `^[а-я]+$` (после `ё`→`е`, нижний регистр);
2. dedup;
3. пересортировка по UTF-8 codepoint;
4. gzip → `app/src/main/assets/balda_dict.txt.gz`.

## Лицензия — остаточный риск

Явной лицензии ни у публикации блога, ни у словаря Хагена не нашлось
(словарь свободно распространяется много лет, но письменного разрешения нет).
Смягчающие факторы: attribution в «О программе»; спорная механика игры
(слов вне словаря не ломают партию — см. §6 протокола) снимает критичность — неполный/спорный словарь
не ломает партию; словарь легко заменить (ассет обновляем,
`balda_extra.txt` для дополнений).

## Связанные материалы (алгоритм, не словарь)

- https://github.com/l1feforce/BaldaSearcher — идея поиска кандидатов:
  DFS по полю с обрезкой ветвей по префиксам словаря (у автора — два
  префиксных дерева, прямое и инвертированное; важно: новая буква может
  быть ЛЮБОЙ буквой слова, не только первой). Лицензии у репо нет —
  код не копируем, идею реализуем по-своему: отсортированный массив +
  бинарный поиск префиксов (см. `BaldaEngine`).
- https://github.com/l1feforce/BaldaGame — Android-игра автора (Kotlin,
  2018–2019, без лицензии) — только для ознакомления.
