# MeshGames Autonomous Server & Smart AI Bot

Автономный многопоточный игровой сервер и сильный ИИ-бот для сети **Meshtastic**, работающий поверх радиоканала LoRa без интернета.

---

## Ключевые возможности

1. **Прямое подключение к физической ноде Meshtastic по IP (TCP порт 4403):**
   - Подключается к любой ноде (Heltec, T-Beam, RAK, Station G2, Linux Native) по TCP.
   - Использует штатный Meshtastic Stream Framing (`0x94 0xC3`, Protobuf `ToRadio`/`FromRadio`).
   - Автоматически считывает `my_node_num` и имя ноды (`long_name` / `short_name`) через `MyNodeInfo` и `NodeInfo`.
   - Периодически шлёт `heartbeat` для поддержания сессии.

2. **Полная замена MeshBridge (маршрутизация и дисциплина радиоканала):**
   - **`want_ack = false` всегда** — никаких firmware-ретрансмитов, сбережение эфирного времени LoRa.
   - **LRU-карта маршрутизации (32 записи):** автоматически обучается на входящих пакетах, связывая `clientId` игрока с `nodeNum` ноды.
   - **Разделение трафика:**
     - `0x50` (Presence) → вещание broadcast (`0xFFFFFFFF`).
     - `0x47` (Envelope) → прямая адресация DM (`to = nodeNum`) при наличии пира в карте; broadcast fallback при отсутствии.
   - **Прямой стек без сторонних прослоек:** сервер напрямую подключается к физической ноде Meshtastic по PhoneAPI (TCP 4403), обеспечивая минимальные задержки и надёжную маршрутизацию.

3. **Многопоточность и одновременная игра:**
   - Сервер всегда в сети (`busy = false` в presence-анонсах).
   - Способен **одновременно играть с несколькими реальными игроками** в разные игры без блокировки основного потока (на корутинах Kotlin).
   - Мгновенно принимает любые входящие приглашения (`INVITE`), а в морском бое автоматически подтверждает расстановку (`READY`).

4. **Продвинутый искусственный интеллект (Smart AI) для всех 6 игр:**
   - **Крестики-нолики (`TttAi`):** полный Minimax с оценкой глубины — математически непобедим.
   - **Шахматы (`ChessAi`):** Minimax с Alpha-Beta отсечением, позиционными таблицами Piece-Square Tables (PST) для всех фигур, упорядочиванием взятий (MVV-LVA).
   - **Шашки (`CheckersAi`):** Alpha-Beta отсечение, цепочки обязательных взятий, превращение в дамки, позиционный контроль центра.
   - **Морской бой (`SeaBattleAi`):** Hunt-and-Target стратегия с тепловой картой вероятностей (Heatmap) и диагонально-паритетной сеткой; добивание раненого корабля строго по линии.
   - **Балда (`BaldaAi`):** DFS-поиск по встроенному словарю существительных русского языка (`balda_dict.txt.gz`, 4140+ слов), поиск самых длинных и выгодных слов, поддержка спорных слов.
   - **Дурак (`DurakAi`):** позиционная оценка руки, сбережение козырей на эндшпиль, минимальный отбой, подкидывание балласта при атаке, автоматический расчет колоды из `sessionId` (детерминизм без передачи скрытых карт в радио).

## Быстрый старт

### Требования
- Linux / macOS / Windows
- JDK 17 или новее (рекомендуется JDK 21+)

### Запуск через скрипт `run.sh`
```bash
cd bot_server
./run.sh --node-host 192.168.1.50 --node-port 4403
```
Если `fatJar` ещё не собран, скрипт автоматически соберет его через Gradle.

### Сборка standalone JAR
```bash
./gradlew :bot_server:fatJar
```
Готовый самодостаточный архив появится в:
`bot_server/build/libs/meshgames-bot-server-all.jar` (~7.6 МБ).

Запуск напрямую через Java:
```bash
java -jar bot_server/build/libs/meshgames-bot-server-all.jar --node-host 127.0.0.1 --node-port 4403
```

## Параметры командной строки

| Флаг | Описание | По умолчанию |
|---|---|---|
| `--node-host`, `-nh`, `--host`, `-h` | IP или хост ноды Meshtastic | `127.0.0.1` |
| `--node-port`, `-np`, `--port`, `-p` | TCP порт PhoneAPI ноды | `4403` |
| `--channel`, `-c` | Индекс канала LoRa (жёсткая привязка) | `0` |
| `--hop-limit`, `-hl` | Лимит ретрансляций LoRa пакетов | `3` |
| `--portnum` | Номер порта приложения в пакете (PortNum) | `69` (SIMULATOR_APP) |
| `--name`, `-n` | Явное имя бота (приоритет 1: если задано, имя ноды не перезапишет) | имя ноды или `MeshBot` |
| `--id` | Стабильный clientId бота (hex или dec) | из `bot_identity.properties` |
| `--difficulty`, `-d` | Сложность ИИ (`easy`, `medium`, `hard`) | `hard` |
| `--delay` | Искусственная задержка размышления бота (мс) | `1000` |
| `--dir` | Каталог хранения сессий, журналов и логов | `bot_data` |

> **Приоритет имени бота:**
> 1. **Имя из параметров запуска** (`--name` / `-n`) — высший приоритет, никогда не перезаписывается именем ноды.
> 2. **Имя ноды** — если параметр `--name` не указан, автоматически берется имя из пакетов `node_info` подключенной ноды.
> 3. **Имя по умолчанию** (`MeshBot`) — используется, если параметр не задан и нода не передала имя.

## Управление во время работы (консоль)

Во время работы сервера в терминале доступны интерактивные команды:

- **`status`** (или **`s`**) — отобразить все текущие активные сессии, оппонентов, игры и стороны.
- **`table`** (или **`t`**) — отобразить полную таблицу статистики: рейтинг игроков, винрейт, число побед/поражений/ничьих и последние партии.
- **`routing`** (или **`r`**) — показать обученную таблицу маршрутизации (`clientId -> nodeNum`).
- **`presence`** (или **`p`**) — немедленно отправить presence-кадр в эфир LoRa.
- **`quit`** (или **`q`**, **`exit`**) — корректно завершить работу сервера.

### Запрос статистики из канала Meshtastic (`!table`)
Любой пользователь в сети Meshtastic может отправить в канал текстовое сообщение:
`!table` или `!таблица`
Сервер автоматически перехватывает его и отправляет в радиоканал краткую сводку топ-игроков, строго соблюдая ограничение по длине ($\le 100$ символов кириллицы / $\le 200$ байт UTF-8).
